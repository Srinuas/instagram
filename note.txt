Based on the reference image 1000444735.jpg, 
the user interface is built using a layered approach with CSS absolute positioning:   
Base Layer: The video tag takes up 100% of the mobile screen (object-fit: cover) acting as the background.   
Top Header: The "← Reels" text sits at the top left. This is also our hidden trigger—double-tapping this opens the admin PIN prompt.   
Right Sidebar: Positioned at the bottom-right, this contains a vertical flexbox for the Like, Comment, and Share icons along with their respective metrics.   
Bottom Info: Positioned at the bottom-left, this contains the overlapping floating avatar circles, the main profile image, the username, the "Follow" button, and the text caption.
